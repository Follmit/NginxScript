# serverScript.sh

1. Чувствительный режим
Прерывание команды в случае ошибки.

2. Чек рут доступа
Проверяет, что запуск скрипта от имени рута. В случае не рута - остановка скрипта.

3. Обновление и установка пакетов
Обновление и установка необходимых пакетов. И включение автоматического обновление патчей безопасности ОС через unattended-upgrades.

4. Установка Docker
Добавление официального докер репозитория. И последующая установка с подписанным ключом.

5. Конфигурирование NetworkSecurity

Настройка файрвола UFW. Закрытие всех портов, кроме 22, 80, 443. 
Настройка fail2ban для защиты SSH. 5 попыток на вход или бан на час.

6. Конфигурирование Nginx
Создание общего шаблона для всех сервисов.

server_tokens off - скрывает версию nginx.
client_max_body_size 16M - размер загружаемых файлов.
#timeout - таймауты запросов.
#Заголовки - защитные заголовки от атак.
#Лимиты - лимиты запросов.

7. Конфигурация Proxy Nginx
Делает конфигурацию FASTAPI.
Если конфиг есть - делает бэкап. И добавляет конфиг для перенаправления всего трафика с 80 порта на адрес FastApi.

8. Проверка nginx
Проверка синтаксиса. Если есть ошибка - скрипт не будет выполнен.


Запуск

chmod +x serverScript.sh
sudo ./serverScript.sh
